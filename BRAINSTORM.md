# Brainstorm — Trackripsi

## Directions

### 1. Tahap Linear & Habit Tracker

**Pengurai skripsi menjadi milestone harian berbasis bab dan fokus menulis.**

- **Audience:** Mahasiswa tingkat akhir overwhelmed yang menunda pengerjaan skripsi.
- **Wedge:** Template roadmap terstruktur Bab 1-5 dengan micro-tasks bawaan. Generic tools seperti Trello butuh setup manual lama.
- **Why now:** Tekanan lulus tepat waktu tinggi pasca-pandemi dan maraknya fenomena skripsi burnout.
- **Business model:** Freemium: gratis 1 riset, bayar sekali (one-time micro-payment) untuk fitur analitik dan unlimited riset.
- **Biggest risk:** Retensi rendah karena user berhenti pakai setelah wisuda (lifetime value pendek).

### 2. Literature & Draft Repository

**Ruang kerja personal untuk simpan versi draft, matriks jurnal, dan riwayat bimbingan.**

- **Audience:** Mahasiswa jurusan riset berat, sains, dan teknik yang punya banyak iterasi file dan jurnal.
- **Wedge:** Penyimpanan terpusat dokumen bab beserta catatan bimbingan tanpa campur dengan file kuliah umum.
- **Why now:** File draft sering berserakan di WhatsApp, email, dan Google Drive tanpa pelacakan versi jelas.
- **Business model:** Langganan per semester murah (student pricing) dengan kuota cloud storage.
- **Biggest risk:** Ketergantungan penyimpanan file meningkatkan biaya storage dan bandwidth VPS.

### 3. Multi-Project Academic Dashboard

**Pusat kendali riset paralel untuk mahasiswa aktif publikasi ilmiah dan tugas akhir.**

- **Audience:** Mahasiswa berprestasi, asisten lab, atau penerima hibah riset (PKM/skripsi paralel).
- **Wedge:** Fleksibilitas mengelola beberapa riset sekaligus dalam satu akun dengan pipeline terpisah.
- **Why now:** Tuntutan kampus merdeka dan publikasi jurnal SINTA sebelum lulus makin meluas.
- **Business model:** Lisensi tahunan flat untuk akses workspace riset unlimited.
- **Biggest risk:** Ukuran pasar ceruk lebih kecil dibanding mahasiswa skripsi reguler.

## Target segments

| Segment | Core pain | Likely to pay |
| --- | --- | --- |
| Deadliner Butuh Struktur | Bingung memulai dari mana, cemas terhadap deadline, dan kehilangan jejak progress Bab 1-5. | Sedang, rela bayar nominal kecil untuk mengurangi stres menjelang deadline yudisium. |
| Asisten Riset / Multi-Paper | Kewalahan mengelola skripsi bersamaan dengan proyek riset dosen atau jurnal PKM. | Tinggi, menghargai efisiensi pengelolaan referensi dan multi-dokumen. |
| Pengejar Target Kelulusan Cepat | Butuh estimasi timeline ketat per bab agar lulus tepat waktu sesuai target beasiswa/pribadi. | Rendah ke Sedang, sensitif harga dan mencari alternatif gratisan kecuali sangat bernilai. |

## Feature ideas

### MVP

- **Workspace Multi-Riset** — Dashboard membuat dan memantau beberapa riset terpisah dalam satu akun user.
- **Roadmap Milestone Bab 1-5** — Checklist hierarkis dari judul, proposal, pengumpulan data, hingga bab kesimpulan dengan visual progress bar.
- **Log Catatan Bimbingan** — Pencatatan tanggal konsultasi, feedback dosen, dan to-do list tindak lanjut hasil revisi.
- **Version Control Dokumen Draft** — Unggah dan riwayat versi berkas naskah (.docx/.pdf) tiap bab untuk menghindari tertukar file.
- **Kalkulator Timeline Target Sidang** — Pengaturan tanggal target yudisium dengan estimasi durasi pengerjaan per bab secara mundur.

### Later

- **Matriks Sintesis Literatur** — Tabel ringkasan paper referensi (metode, variabel, temuan) per riset.
- **Pengingat & Pomodoro Fokus Menulis** — Timer fokus sesi menulis harian terintegrasi dengan pencatatan kata/halaman terselesaikan.
- **Ekspor Ringkasan Portofolio Skripsi** — Generate laporan PDF riwayat kemajuan riset untuk arsip pribadi atau evaluasi mandiri.

## Name ideas

`TuntasSkripsi` · `BabSatu` · `SidangRapi` · `SkripsiTrack`

## Risks

- Biaya akuisisi user baru tinggi setiap tahun karena siklus pakai pengguna berakhir saat lulus.
- Kecenderungan mahasiswa memakai Notion, Trello, atau Google Docs gratisan yang fleksibel.
- Disiplin input manual data progress riset menurun saat mahasiswa mengalami writer's block.

## Assumptions to validate

- [ ] Mahasiswa tingkat akhir membutuhkan struktur bawaan skripsi dibanding membuat to-do list dari nol di generic tools.
- [ ] Fitur tracking mandiri tetap bernilai tanpa integrasi langsung ke sistem kampus atau interaksi dosen.
- [ ] Workflow skripsi Bab 1 sampai Bab 5 cukup seragam lintas fakultas untuk dijadikan template standar aplikasi.
- [ ] Mahasiswa bersedia membayar biaya terjangkau secara mandiri tanpa subsidi dari pihak kampus.
